  **01**   **产品愿景与定位**

  -------- ----------------------------------------------------------------

**1.1 产品名称与核心定位**

CryptoLens ------ 让每一个加密货币新手都能在 5 分钟内读懂今天的市场。

  -------------- ------------------------------------------------------------------------------------------------------------------------------------------------------
  **核心主张**   聚合 YouTube、X（Twitter）、主流媒体的最新 Crypto 资讯，通过 AI 去术语化处理、重要性分级和情境化解读，帮助新手用户真正读懂加密市场，而非被信息淩没。

  -------------- ------------------------------------------------------------------------------------------------------------------------------------------------------

**1.2 市场背景**

全球加密货币持有者已超过 5.6 亿（2024 年），其中 72% 年龄在 34 岁以下。然而给大多数主流 Crypto 资讯平台仍以中高级用户为默认受众，造成三大系统性断层：

-   认知断层：Gas fee、DeFi、链上数据等专业术语频繁出现，新手被迫离开页面去外部搜索

-   情绪断层：焦虑触发信息消费，但平台提供的是事实流，而非情绪锡定

-   行动断层：看完新闻不知如何响应，信息消费与个人决策完全脱节

**1.3 产品愿景声明**

  ---------- ----------------------------------------------------------------------------------------------------------------------------------------------------------
  **愿景**   成为 Crypto 新手的第一个懂他的朋友------在每一次市场波动时，第一时间告诉他这件事是否值得担心、为什么发生、对他意味着什么，帮助他从被动焦虑走向主动认知。

  ---------- ----------------------------------------------------------------------------------------------------------------------------------------------------------

**1.4 内容聚合策略**

  ------------------------ ------------------------------------------------------------------------
  **来源类型**             **典型渠道与说明**

  视频平台                 YouTube 加密主流 KOL（Coin Bureau、Benjamin Cowen 等）、官方频道短视频

  社交媒体                 X（Twitter）------ Crypto CT 实时 Alpha、主流 KOL 推文

  专业媒体                 CoinDesk、Cointelegraph、Decrypt、The Block

  官方公告                 美联储、SEC、各国监管机构相关声明

**3.2 P0 功能详细规格**

**3.2.1 每日精选 Breaking News**

每日编辑精选 3-5 条最重要资讯，用户可在 5 分钟内完成当日信息消费。提供每日版和每月版两种时间粒度。

  ------------------------ ------------------------------------------------
  **规格项**               **说明**

  内容形式                 文字摘要（200字内）+ 要点 3 条 + 重要性标签

  更新频率                 每日 08:00（本地时间）推送；重大事件实时插入

  来源标注                 显示原始来源媒体名 + 发布时间 + 内容类型标签

  重要性分级               高 / 中 / 低，由 AI 初判 + 编辑人工校验

  去术语化                 所有专业词汇自动高亮，点击展开简明定义卡片

  分享                     一键生成带重要性标签的图片卡，可分享至社交媒体
  ------------------------ ------------------------------------------------

**3.2.2 术语智能解释层**

在所有内容中识别专业 Crypto 术语，提供内联解释，用户无需离开当前页面即可理解。

  ------------------------ ----------------------------------------------------------
  **规格项**               **说明**

  触发方式                 高亮词汇点击或长按，弹出解释卡片（不跳转页面）

  解释格式                 3 句话以内，用类比代替定义（Gas fee 就像发快递要付邮费）

  词库规模                 初期覆盖 300+ 核心术语，持续扩展

  个性化                   用户已查看的术语标记为已掌握，减少视觉打扰

  学习追踪                 我的词汇库面板显示已掌握术语数，提供成就感
  ------------------------ ----------------------------------------------------------

**3.2.3 短视频新闻卡片**

聚合来自 YouTube、X 等平台的 60-180 秒短视频，以登版卡片流形式呼现，适合碎片化消费。

  ------------------------ ------------------------------------------------
  **规格项**               **说明**

  视频来源                 YouTube 精选频道 + X 视频 + 原生短视频

  展示形式                 登版卡片（类 TikTok 形式），配 AI 生成摘要字幕

  分类标签                 重大事件 / 价格分析 / 基础知识 / 市场情绪

  时长筛选                 用户可设定偏好时长（\<1分钟 / 1-3分钟 / 不限）

  播放设置                 默认静音自动播放；支持离线缓存
  ------------------------ ------------------------------------------------

**4.2 新手首次使用流程（FTUE）**

  -------------- --------------------------------------------------------------
  **设计原则**   让用户在注册前先感受到产品价值------先展示内容，再要求注册。

  -------------- --------------------------------------------------------------

1.  进入 App → 展示今日 3 条精选资讯（无需注册，游客模式可读）

2.  第一条资讯包含 2-3 个高亮术语 → 引导用户点击体验解释卡片功能

3.  阅读完成后推送软注册引导：注册即可开启个性化推送和持仓解读

4.  注册后询问：你已持有哪些加密货币（非必填，可跳过）→ 个性化内容开始

5.  第 3 天使用：推送「已掌握 5 个 Crypto 术语」成就通知 → 强化留存动机

**4.3 内容处理管线**

  ----------------- -------------------------------------------------------------
  **Step 1 抓取**   定时爬取 YouTube 字幕、X 帖子、媒体 RSS，结构化存储

  ----------------- -------------------------------------------------------------

  -------------------- -------------------------------------------------------------
  **Step 2 AI 处理**   重要性打分 · 术语识别 · 去情绪化处理 · 摘要生成 · 分类打标

  -------------------- -------------------------------------------------------------

  --------------------- -------------------------------------------------------------
  **Step 3 编辑审校**   人工编辑确认重要性等级，过滤低质量或误导性内容

  --------------------- -------------------------------------------------------------

  ----------------------- -------------------------------------------------------------
  **Step 4 个性化推送**   根据用户关注币种 + 阅读历史 + 时区，生成个性化推送

**6.1 商业模式设计**

CryptoLens 采用「免费获取用户 → 价值验证 → 高价值用户付费转化」三阶段路径。核心原则：绝不在新手体验最关键的功能上设付费壁。

**免费层（Free）**

-   每日精选 3 条 Breaking News

-   术语解释层（全量开放）

-   短视频新闻卡片（基础功能）

-   来源可信度标注

-   每月月报（基础版）

**Premium 层（参考定价 \$6-10 / 月）**

-   无限量新闻阅读（免费层仅限每日 3 条）

-   情境化持仓解读（关注所有币种）

-   个性化推送定制

-   月报完整版 + 历史归档

-   无广告体验

-   新功能优先体验资格

**6.2 变现时序建议**

  ------------------------ -----------------------------------------------------------------------
  **阶段**                 **变现策略**

  Month 1-6 用户增长期     完全免费，不做任何商业化。专注用户留存和口碑建立

  Month 7-9 验证期         推出 Premium 内测，邀请核心用户以优惠价参与，验证付费意愿和价格敏感度

  Month 10+ 商业化期       正式上线订阅制；探索与 Crypto 交易所合作的内容联营模式

**7.2 差异化核心竞争力**

  ---------------- ----------------------------------------------------------------------------------------------------------------------------------------------------------
  **核心差异化**   CryptoLens 是唯一一款将「术语解释层 + 重要性评级 + 情境化持仓解读」系统性整合进资讯 App 的产品，从新手的真实使用旅程出发设计，而非从信息生产者视角出发。

  ---------------- ----------------------------------------------------------------------------------------------------------------------------------------------------------

-   内容运营护城河：专业编辑维护的新手术语库，AI 辅助生成但人工校验，质量壁垒需要时间积累

-   用户行为数据护城河：随使用积累的术语掌握记录和阅读偏好，形成个性化推荐壁垒

-   内容信任护城河：来源标注 + 去情绪化处理形成的中立品牌，是新手用户最稀缺的价值

  内容质量风险   AI 处理出现事实性错误或误导性解读，损害用户信任   编辑双重审校 + 用户举报系统 + 72 小时响应机制

  监管合规风险   被认定为提供投资建议，触发金融监管要求            所有内容标注「仅供参考」，情境解读明确排除投资建议，咋询法律顾问

  内容版权风险   聚合第三方内容可能触发版权纠纷                    遵守 Fair Use 原则，仅展示摘要 + 跳转原始链接，与主要来源建立合作协议

  用户增长风险   Crypto 市场进入熊市，新用户涌入放缓               内容价值不依赖牛市，重点打造「无论涨跌都有用」的学习类内容

  竞品跟随风险   CoinDesk、Decrypt 等大平台快速跟进同类功能        通过深度内容运营和用户数据积累建立先发壁垒；专注新手服务而非追求全量用户
