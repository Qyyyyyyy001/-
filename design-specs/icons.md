# Icons 图标库

> 来源 Figma 节点: `1:393`（Color 区块包含图标库部分）

Figma 中的图标库被组织为 5 大分类，每个分类标注了 `Last Updated MM/DD/YYYY`。以下为分类索引（具体图标资产请从 Figma 文件导出）。

## 1. Header Icons

页面顶栏 / 导航栏图标，例如：菜单、搜索、消息、用户、设置、语言、主题切换等。

## 2. Social Media Icons

社交媒体平台图标，例如：Twitter / X、Telegram、Discord、Medium、Github、LinkedIn、YouTube 等。

## 3. Common Currency Icons（常见币种图标）

主流加密币种 logo，例如：BTC、ETH、USDT、USDC、BNB、SOL、TRX、XRP、ADA、DOGE 等。

## 4. Common Currency Chain Icons（常见币种链图标）

主流公链 logo，例如：Ethereum、Bitcoin、TRON、BNB Chain、Solana、Polygon、Arbitrum、Optimism、Base 等。

## 5. Common Fiat Currency Icons（常见法币图标）

法币 logo / 国旗符号，例如：USD、EUR、CNY、JPY、GBP、HKD、SGD 等。

## 使用规范

- 图标默认描边色：`Icon/Icon-Primary` (`#303236`)
- 次级图标：`Icon/Icon-Secondary` (`#484B51`)
- 三级图标：`Icon/Icon Tertiary` (`#84888C`)
- 反色 / 深底图标：`var(--color-text-always-white)` (`#FFFFFF`)
- 推荐尺寸跟随按钮 / 列表的尺度：`12 / 14 / 16 / 18 / 20 / 24 px`
- 法币与币种 logo 应保留品牌色，不要重新着色。

> 实际图标 SVG 资产没有随本次导入落库；当需要使用具体图标时，请从 Figma 文件按需导出，并放置到 `design-specs/icons/<category>/` 目录下。
