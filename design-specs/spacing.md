# Spacing 间距规范

> 来源 Figma 节点: `33:296` (Spacing) → `Spacing_V5`

间距 token 同时提供 **Vertical（纵向 padding/margin/gap）** 与 **Horizontal（横向 padding/margin/gap）** 两套，使用相同的数值刻度。命名规则：`Type=<Vertical|Horizontal>, Value=<px>`。

## 完整刻度

| Token (Value) | 像素 | 典型用途 |
| ---: | ---: | --- |
| 4 | 4px | 紧密间距、icon-text 间隔 |
| 8 | 8px | 行内紧凑组件之间 |
| 12 | 12px | 表单控件内部、列表项内边距 |
| 16 | 16px | 卡片内边距、段落间距 |
| 20 | 20px | 中型组件之间 |
| 24 | 24px | 区块间距 |
| 28 | 28px | 中型 padding |
| 32 | 32px | 大区块边距 |
| 40 | 40px | 大段落 / 大区块 |
| 48 | 48px | 模块分隔 |
| 64 | 64px | 大模块分隔 |
| 72 | 72px | 节标题上下 |
| 80 | 80px | 页面级分隔 |
| 100 | 100px | 大型留白 |
| 120 | 120px | 大型留白 |
| 140 | 140px | 大型留白 |
| 160 | 160px | 大型留白 |
| 180 | 180px | 大型留白 |
| 200 | 200px | 营销页区块 |
| 240 | 240px | 营销页大区块 |

## 使用建议

- **基础单位**：4px。所有间距均为 4 的倍数。
- **小尺度**（≤ 24）用于组件内部、组件之间。
- **中尺度**（28 ~ 64）用于区块/卡片之间、模块标题上下。
- **大尺度**（≥ 80）一般只在营销页、Landing Page、说明性区块使用。
- **方向**：横向（Horizontal）一般作为 `gap` 或 `padding-x`；纵向（Vertical）一般作为 `padding-y` 或纵向 `gap`。
